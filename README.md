# Perception Algorithm Practice

## 项目目标

- 夯实 Python、NumPy 与科学计算基础。

- 通过可运行代码、实验记录和 Git 提交形成可展示的项目成果。
- 后续扩展到图像鲁棒性、点云处理和多传感器融合。
